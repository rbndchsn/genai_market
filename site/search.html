Search

Search every insight, statistic, vendor profile, glossary term, taxonomy entry and source on the site. Results link straight to the record.

This is a plain keyword search, not an AI assistant. It matches the words you type against an index of the site's own text, entirely in your browser. Nothing is sent to a server and no model interprets your question or writes an answer.

How this search works, and how it differs from AI search

What it does

When the site is published, every record is split into words and stored in a small index. When you search, your words are normalised the same way, and each one must appear in a record for it to be listed. A word also matches longer words that start with it, so "agent" finds "agentic". Results are ranked by how rare each matched word is across the site, with a boost when it appears in the record's title, and a small preference for findings and definitions over raw statistics. Every result is an existing record; nothing is generated.

What it does not do

It does not understand meaning. A synonym the record never uses returns nothing, there is no spelling correction, and a question typed as a sentence will match only its individual words. Use the vocabulary you expect to see in the text, and use the Glossary to find that vocabulary.

Alternatives you may have met elsewhere

  • Semantic search turns text and query into numeric vectors with an embedding model and returns the closest matches by meaning, so different wording still finds the record. It needs a model at indexing and query time and usually a server.
  • Retrieval-augmented generation (RAG) retrieves passages by keyword or meaning and then has a language model write an answer from them, ideally with citations. The answer is generated, so it can be wrong or incomplete even when the passages it drew on were right.
  • A chat assistant is RAG with a conversation on top: follow-up questions, clarifications and summaries across records.

This site uses keyword search on purpose. Every result is a real record you can open and check against its references, results are the same for everyone, and no text leaves your browser.
